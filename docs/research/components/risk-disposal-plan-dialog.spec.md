# 处置计划弹窗复刻规格

来源：`http://172.16.40.152:8101/#/riskMonitor/info`，风险“上海均和产业发展集团有限公司”的“处置计划”操作。

- 容器：Element Plus `el-dialog`，白色、4px 圆角、24px 内边距；参考视口 1536px 时宽 1024px（`width: 2/3 viewport`），顶部间距 12px。
- 标题栏：标题 16px / 24px，右侧关闭按钮；标题栏右侧保留 32px，标题下方 16px 空白。
- 完成摘要：浅蓝 `#e8f4ff`，圆角 6px，内边距 `10px 15px`，底部 15px 间距；显示完成状态标签与“申请完成：n 步 / 共 n 步”。
- 总目标卡：`#f5f7fa`、8px 圆角、`16px 20px` 内边距、高 80px；标题、目标值、主责企业和计划完成时间；右侧蓝色“修改处置计划”。
- 明细表：14px 字号，表头 27px、数据行约 57px；列为“步骤、内容、责任人、计划完成时间、实际完成时间、状态、操作”。
- 分页：表格下方，14px 字号，显示“共 n 条、10条/页、‹、1、›、前往、页”。无“确定”按钮。

## 无计划状态

- 风险没有处置计划步骤时，点击操作应直接打开单层“制定处置计划”弹窗，不能先显示“处置计划”容器再叠加第二层。
- 创建窗显示主责企业、风险内容、计划总目标、计划截止日期、默认第一步骤和“⊕ 添加步骤”。
- 保存或取消均关闭该唯一弹窗。
