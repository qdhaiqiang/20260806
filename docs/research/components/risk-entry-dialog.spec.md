# 风险信息新增弹窗规格

## 概述

- 目标：风险信息检索区“查询”左侧的“新增”按钮。
- 交互：点击后打开“新增风险信息”表单；保存后在当前会话的风险表中插入一条模拟企查查/运营平台风险记录。
- 数据边界：不写入导入的 SQLite 库，不创建或修改表结构。

## 字段

- 企业名称、企业分组、管理主体、主管部门。
- 风险指标从本地“指标管理”接口 `/api/supervise/index/page` 加载后选择；选择后带入指标主类、类型、等级及可用主管部门。
- 风险主类、风险类型、风险内容、风险级别、风险状态、风险来源、发生日期。
- 股权结构图为本地图片附件上传并在表单内预览；持股比例、投资金额、企业信用代码、企查查 ID、指标别名编码。

## 控件

- 企业分组、管理主体、主管部门、风险指标、风险主类、风险类型、风险级别和风险来源必须为下拉选择。
- 风险状态在新增时固定显示“未确认”，保存的 `operationStatus` 固定为 `0`，不允许在新增表单内改为已确认状态。
- 风险内容为多行文本域；其他自由文本字段为单行输入。
- 底部右对齐“保存”和“取消”。
